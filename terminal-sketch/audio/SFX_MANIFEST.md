# KOSMOS generated SFX pack

These files were procedurally generated for the game and are safe to use as original project assets.

## Loops

- `sfx/ambient_ship_loop.wav` - seamless quiet ship/terminal bed after boot.
- `sfx/ambient_nav_loop.wav` - seamless orbital planner ambience.
- `sfx/ambient_sedation_loop.wav` - seamless medical reinduction ambience.

## Replacement sources

- Mixkit: free sound effects with a simple free license for personal and commercial projects.
- Kenney Interface Sounds: CC0 interface/game UI sounds.
- Pixabay Sound Effects: royalty-free sound effects; check each asset page before use.
- Freesound: excellent library, but filter for CC0 or track attribution carefully.
