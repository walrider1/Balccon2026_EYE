MEDICAL // QUICK INSTRUCTIONS

Type one command at a time, then press Enter. No coding required.

FIRST: RESTORE MEDICAL ACCESS
"auth" means authorize. The domain says WHICH controller; the code is its password.
Example: auth medical MR-07-0412
Here medical is the domain, and MR-07-0412 is the code.
Join MR, your chamber number and the override date with hyphens.
CHAMBER: 07
DATE: 04/12 becomes 0412 (remove the slash).
TYPE: auth medical MR-07-0412

NEXT: OPEN COMMUNICATIONS
TYPE: cd /comms
TYPE: ls
Read recovery_service.txt there with cat recovery_service.txt.
Cortex is not your next step yet.

LATER: ONLY IF THE SEDATION COUNTDOWN STARTS
Sedation means being put to sleep with medication. When its timer reaches zero,
you lose consciousness and the session ends. Cortex can stop that.
"run" starts an application; "cd" only changes your folder.
TYPE: run /medical/cortex_echo.app
Already inside /medical? run cortex_echo.app works too.
Press the displayed A/S/K/L key; pass 15 of 20 signals.
Submit the code you receive: auth cortex <your-code>
Then type: root recover
